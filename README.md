# Thailand Water Storage Decision Support System

Interactive Streamlit app for water storage change in Thailand and its 22 river basins, 2002–2024.

- Earthquake-corrected GRACE/GRACE-FO storage from five products
- Climate-driven storage from a physical model and a random forest
- Residual storage (human water use + model error)
- Adjustable basin priority index

## Run locally

    pip install -r requirements.txt
    streamlit run app.py
